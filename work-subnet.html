Network Subnetting Calculator Tool

Built because I was tired of doing /26 math on a billing counter while someone waited.

The situation

Every VLAN job = subnet math. How many hosts in /27? What's the mask for 4 subnets? I kept opening random websites with 10 popups. So I made a tiny offline page: type IP + CIDR, get network, broadcast, mask, hosts, and equal subnets. No ads, no login, works without internet — important in a basement server room.

Joke: my first version said /32 has 1 host and -1 usable. Networking humor. Fixed now.

Network Topology

None — it's a browser tool. But here's the logic:

[Input: 192.168.10.0/24 + split into 4]
   -> mask 255.255.255.192 (/26)
   -> 4 subnets x 62 usable hosts
   -> lists network / first / last / broadcast per subnet

Hardware Used

  • HTML + CSS + JavaScript, single page, runs offline
  • Hosted as subnet.html on this site — zero cost
