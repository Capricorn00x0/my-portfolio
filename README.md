# my-portfolio

Static portfolio site — Mohammed Fahim | Network Engineer.

## Run locally

Just open `index.html`, or serve the folder:

```bash
npx serve .
```

## Deploy to Vercel

1. Push to GitHub (`main` branch).
2. Go to [vercel.com/new](https://vercel.com/new) → Import `my-portfolio`.
3. Framework Preset: `Other`. No build command. Output: `.` (root).
4. Deploy.

`vercel.json` enables clean URLs (`/about` → `/about.html`).
