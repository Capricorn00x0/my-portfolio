Enterprise Multi-VLAN Network Setup

One office, three floors, everybody on 192.168.1.x and everybody shouting. Printers getting ARP storms, guests on the same LAN as Accounts. Classic.

The situation

Small company, about 60 devices. One flat network. The Accounts PC shared a broadcast domain with the guest Wi-Fi — yes, really. Every time someone plugged a cheap switch looped back on itself, the whole floor went down and I got the call. My job: split it up without buying new routers, and without breaking anything on a working weekday.

Humor break: the "server room" was a store room with a mop bucket next to the rack. I moved the bucket first. Priorities.

Network Topology

[ISP Router]
    | (trunk, VLANs 10,20,30,40)
[Core L2 Switch - Ground Floor]
    |-- trunk -- [Floor 1 Switch] -- Staff PCs (VLAN 10)
    |-- trunk -- [Floor 2 Switch] -- Accounts (VLAN 20) + Printers (VLAN 40)
    +-- access -- Guest AP (VLAN 30, isolated)
VLANNameSubnetPurpose
10Staff192.168.10.0/24Office PCs, Wi-Fi staff SSID
20Accounts192.168.20.0/24Tally / billing PCs only
30Guest192.168.30.0/24Guest Wi-Fi, internet only
40Printers192.168.40.0/24Printers + scanner, shared controlled

Inter-VLAN routing done on the existing router (router-on-a-stick, one trunk port, sub-interfaces). ACLs: Guest → internet only, no LAN. Accounts → Staff printers allowed, Staff → Accounts blocked except gateway.

Hardware Used

  • Existing ISP router (reused, added sub-interfaces — no new purchase)
  • 3× managed L2 switches (VLAN + trunk support)
  • Patch panels, Cat6 re-labelling, cable ties (so many cable ties)
  • 2× access points with multi-SSID

What I actually did

Friday evening: backup of all switch configs to a USB stick and my laptop. Drew the VLAN map on paper because Packet Tracer lies and paper doesn't. Saturday: created VLANs, set trunk ports, moved one floor at a time, tested ping + printing after each floor. The Accounts printer "disappeared" for 20 minutes — turned out it had a hardcoded gateway from 2019. Fixed, felt like a hero. Sunday: guest portal test with 10 phones, DHCP scope check, labelled every port.

Results

  • Broadcast domain split from ~60 devices into 4 small ones — random slowdowns stopped.
  • Guest network fully isolated from Accounts. Owner stopped worrying.
  • Loop on Floor 1 now kills only Floor 1, not the whole building. Progress.
  • Documentation: one-page IP + VLAN sheet taped inside the rack. Future-me says thanks.

Not hyped: still single router, no redundancy. If it dies, we cry. Phase 2 would be a second link — for now, config backup + spare switch on shelf.
